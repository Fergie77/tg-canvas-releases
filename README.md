# TG Canvas

Downloads for TG Canvas, Toogallus's design tool. The source code is kept elsewhere; this
repository only holds the installers.

**[Download the latest version](https://github.com/Fergie77/tg-canvas-releases/releases/latest)**

## Install (macOS, Apple silicon)

1. Download the `.dmg` from the latest release.
2. Open it and drag **TG Canvas** to Applications.
3. The app isn't notarized yet, so the first time right-click it in Applications and choose **Open**.

TG Canvas is based on FigCraft by the ArtCraft team (MIT OR Apache-2.0).
